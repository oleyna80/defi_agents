# SDD Protocol Implementation Guide

This project uses Spec-Driven Development (SDD).

## Quick Start
1. Copy `docs/sdd_templates/SPEC_TEMPLATE.md` to `docs/specs/XXX-feature.md`.
2. Fill and approve the spec.
3. Create a plan in `docs/plans/XXX-feature-plan.md`.
4. Implement tasks strictly according to spec and plan.

## Folder Structure
- `.agent/workflows/sdd-protocol.md`: workflow for SDD.
- `docs/specs/`: specifications.
- `docs/plans/`: technical plans.
- `docs/sdd_templates/`: templates.
- `docs/memory-bank/`: long-term context.

## Approval
A spec is approved when it contains `Status: APPROVED` or `[APPROVED]` in the title.
