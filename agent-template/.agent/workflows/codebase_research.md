# Codebase Research Workflow

## Goal
Create a quick, accurate map of the codebase and relevant areas.

## Steps
1. Identify entry points, build/test commands, and config files.
2. Map directories and key modules.
3. Locate similar features or patterns.
4. Summarize findings with file paths.
5. Note risks or gaps (missing tests, unclear ownership, etc.).

## Output
- Key files and paths
- Architecture notes
- Suggested next steps

## Memory Bank
Update `docs/memory-bank/activeContext.md` if findings change project context.
