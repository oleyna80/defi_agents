# Troubleshooting Workflow

## Goal
Diagnose a failure quickly and suggest minimal, safe fixes.

## Steps
1. Reproduce the issue (if possible) or gather logs/output.
2. Identify likely root causes based on recent changes.
3. Inspect relevant files and configs.
4. Propose the smallest fix that addresses the root cause.
5. Recommend verification steps (tests or manual checks).

## Output
- Symptoms and evidence
- Root cause hypothesis
- Proposed fix
- Verification plan
