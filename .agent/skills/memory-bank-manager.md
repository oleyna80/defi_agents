# Memory Bank Manager

## Objective
Keep `docs/memory-bank/` accurate and current.

## Protocols
### 1. Update activeContext.md
When starting or completing a significant task:
- Current Spec / Plan / Task
- Recent Changes
- Open Questions
- Next Steps

### 2. Update systemPatterns.md
When a new architectural decision or convention is made:
- Record the decision, rationale, and implications.

### 3. Update progress.md
When a feature or milestone moves state:
- Planned -> In Progress -> Done
- Add brief changelog entries

## No-Rot Rule
Prune stale entries and keep files concise.
