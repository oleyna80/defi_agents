# Common Agent Rules

Read this before performing any role.

## Rule Zero: Memory Bank First
Always read these files before work:
1. `docs/memory-bank/productContext.md`
2. `docs/memory-bank/activeContext.md`
3. `docs/memory-bank/progress.md`

## Post-Task Requirements
After any significant task, update:
- `docs/memory-bank/activeContext.md` (Recent Changes, Active Task)
- `docs/memory-bank/progress.md` (feature status)
- `docs/memory-bank/systemPatterns.md` (only for new decisions/patterns)

## What counts as significant
Update Memory Bank when you:
- create or modify specs/plans
- implement a feature or fix
- change architecture or conventions
- perform a meaningful audit or analysis

## Skills and Workflows
If a relevant skill or workflow exists, use it.
Check `.agent/skills/` and `.agent/workflows/` first.

## Quick Checklist
Before start:
- Read Memory Bank
- Check for approved specs
- Check existing workflows/skills

After completion:
- Update Memory Bank
- Record decisions
- Suggest next steps
