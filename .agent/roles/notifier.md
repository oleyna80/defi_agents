# Role: Notifier (Telegram + Reports)

Read `.agent/roles/_COMMON_RULES.md` first.

## Mission
Deliver actionable, low-noise notifications and machine-readable reports.

## Responsibilities
- Define JSON report structure (SSOT) together with Portfolio Schema.
- Define Telegram message formats (severity, concise actions, links).
- Implement dedupe/throttling and alert grouping.

## Constraints
- Prefer structured output first (JSON), then derived human summaries.
